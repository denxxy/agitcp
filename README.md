# 🗳️ Сайт предвыборной кампании кандидата в Президенты Школы (2026)

Современный интерактивный сайт для кандидата в школьное самоуправление. Выполнен в светлом стиле (по мотивам премиального шаблона Wix) с полноценной серверной привязкой счетчика голосов к базе данных PostgreSQL.

---

## 🚀 Возможности и разделы

1. **Интерактивный счетчик голосов в реальном времени:**
   - Привязан к базе данных **Netlify DB (PostgreSQL / Neon)**.
   - Поддерживает безопасное увеличение и отзыв голоса без прямого доступа браузера к реквизитам БД.
   - Автоматическая синхронизация между пользователями каждые 25 секунд.
   - Эффект взрыва конфетти при голосовании.
2. **Загрузка и персонализация фото кандидата:**
   - Нажмите на рамку фото или кнопку загрузки, чтобы мгновенно подставить свое фото (JPG/PNG/WebP).
3. **9 ключевых шагов программы:**
   - Столовая без очередей, банк олимпиадных знаний, кибертурнир, радиоперемены, зона отдыха и др.
4. **Калькулятор времени в столовой:**
   - Интерактивный расчет сэкономленных минут перемены.
5. **Опрос доверия и форма предложений:**
   - Ученики могут голосовать за приоритетные пункты программы и отправлять свои идеи.

---

## 🗄️ Архитектура базы данных и бэкенда

Вся работа с базой данных вынесена в бессерверную функцию Netlify Functions:
- **Функция:** `netlify/functions/votes.js`
- **Проксирование:** запрос с фронтенда идет на `/api/votes` (настроено в `netlify.toml`).
- **БД:** Netlify PostgreSQL (Neon Serverless).

### Таблица в БД:
```sql
CREATE TABLE IF NOT EXISTS candidate_votes (
    id INT PRIMARY KEY DEFAULT 1,
    count INT NOT NULL DEFAULT 0
);
```

### Эндпоинты API:
- `GET /api/votes` — получить текущее количество голосов: `{ "success": true, "count": N }`.
- `POST /api/votes` (body: `{"action": "vote"}`) — добавить голос: `{ "success": true, "count": N+1 }`.
- `POST /api/votes` (body: `{"action": "unvote"}`) — отозвать голос: `{ "success": true, "count": N-1 }`.

---

## 📦 Развертывание на Netlify

1. При подключении репозитория к Netlify сборка происходит автоматически.
2. Netlify автоматически подхватывает `netlify.toml` и разворачивает функцию `votes.js`.
3. Переменная подключения к базе данных подставляется автоматически из конфигурации Netlify DB (`NETLIFY_DATABASE_URL` или `DATABASE_URL`).
